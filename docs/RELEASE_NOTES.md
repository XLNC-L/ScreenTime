## v1.3.5 — 中文安装向导、安装位置可选、产物精简

这一版只改「怎么装」和「包有多大」，运行行为与上一版一致。

### 安装向导

- 界面改为**简体中文**。Inno Setup 官方安装包不含中文语言文件，中文翻译随仓库放在
  `installer/languages/ChineseSimplified.isl`，所以向导不再是一路英文。
- 安装前先选「仅为我安装」或「为所有用户安装」：
  - **仅为我安装**（默认）：装到 `%LocalAppData%\Programs\ScreenTime`，不需要管理员权限；
  - **为所有用户安装**：装到 `Program Files\ScreenTime`，需要 UAC。
- 「选择目标位置」页始终显示，可改到 D 盘等任意路径；覆盖升级沿用上次的安装目录。
- 卸载 / 覆盖升级会自动结束运行中的界面与采集器，不用先手动退出托盘。

### 体积

- 去掉调试符号（`*.pdb`）与符号读取器（`Microsoft.DiaSymReader`），WinUI 语言资源只保留
  简体中文 / 繁体中文 / 英文：**473 → 304 个文件**，安装包 **52.4 MB → 51.5 MB**。
- `Microsoft.UI.Xaml.Phone.dll` 保留不动 —— 实测它是 WinUI 启动期硬依赖，删掉界面直接起不来。

### 运行开销

- 实测空闲 30 秒：采集器 CPU 占用 0.00%、私有内存约 26–31 MB；界面关闭即退出，采集交给常驻 Agent。
  这一版不为省几 MB 去降低采集频率。

### 已知限制

- 仅支持 x64，没有 ARM64 构建。
- 浏览器页面级统计只支持 Chrome / Edge；Firefox 未实现。
- 窗口切换次数从 v1.3.2 开始统计，更早的历史没有这部分数据。
- 安装器未做代码签名，首次运行可能出现「未知发布者」提示。
