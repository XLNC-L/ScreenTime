## v1.3.4 — 数据可信度、长期可用性与行为洞察

这一版补上三件事：**数据准不准、库会不会无限长大、能不能看懂自己在做什么**。

### 运行状态与数据检查

- 设置页新增「运行状态」卡片：前台/音频两条通道最近一次成功采集时间、采集器运行时长与重启次数、
  数据库大小与明细条数、累计异常次数与最后一条。数据全部来自本机，不联网。
- 新增「数据检查」：最近 7 天是否有超过 6 小时的前台片段、是否超过 24 小时没有新记录。
  **只提示可疑之处，不替你判定对错。**
- 采集异常不再静默：原先直接吞掉的异常改为限频记录（10 分钟一条），累计次数可在卡片里看到。

### 明细保留（默认 60 天）

- 到期后把明细**折叠成按日汇总再删除**，而不是直接丢数据：应用排行、网页域名、用途分布、
  每日总时长仍然可查，只是没有逐条明细与窗口标题/网页地址。
- 可选 0 / 30 / 60 / 90 / 180 / 365 天，0 表示永久保留。
- 删除前自动备份到 `%AppData%\ScreenTime\backups\`（保留最近 3 份），每月执行一次 VACUUM。

### 网页隐私

- 敏感域名（内置邮件、网银、密码管理器，可在设置里追加）在**采集、历史回填、网页页展示**三处一起排除。
- 网页地址会去掉 fragment 与 `utm_*`、`gclid` 等追踪参数。
- 「浏览器标签页统计」开关现在同时控制左侧「网页」入口：关掉入口隐藏，**历史数据不删**。
- 新增「清除网页记录」：只清网页地址与域名统计，应用时长保留。

### 洞察与提醒

- 历史页新增「洞察」：与上一周期对比（总时长变化、使用最多的应用）、最长连续使用、日均窗口切换次数。
- 设置页新增「目标与提醒」：游戏 / 影音 / 社交每日目标、连续使用提醒（**默认全部关闭**）。
  命中时只在应用内弹非模态提示，不锁屏、不强制退出；同类提醒每天一次，可「今天不再提醒」。

### 迁移与兼容

- 数据包导出 / 导入：单个 zip（数据库 + meta.json）；导入前自动备份当前库并校验文件头，导入后自动补结构。
- 补齐 DPI 感知清单，修复第三方输入法（微信输入法）候选窗看不见的问题。
- 今日时间线最右侧刻度不再被裁成 `00…`。

### 已知限制

- 仅支持 x64，没有 ARM64 构建。
- 浏览器页面级统计只支持 Chrome / Edge；Firefox 未实现。
- 窗口切换次数从本版开始统计，更早的历史没有这部分数据。
